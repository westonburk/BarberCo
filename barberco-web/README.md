# BarberCo Web

Customer-facing site for Mike's Barber Shop. Next.js app that talks to BarberCo.Api.

## Local development

```bash
npm install
cp env.example .env.local   # add API_BASE_URL and API_KEY
npm run dev
```

## Docker

Built from `Dockerfile` in this directory. See the repo root `docker-compose.yml` for production deployment.
